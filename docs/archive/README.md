# Development log

This folder is the raw development log of Bifrost: the stage plans, the write-up of every chunk of
work, the independent reviews and the by-hand test checklists, kept as they were written. Names
changed along the way (Warden, then Heimdall, became Vidar; Citadel and Mímir became Mimir; ODIN
became Bifrost), and old files keep the names they had. For the readable version of the story, start
at [../HOW-IT-WAS-BUILT.md](../HOW-IT-WAS-BUILT.md).

| Path | What is in it |
|---|---|
| [NAVIGATOR.md](NAVIGATOR.md) | An index of the whole repo, with a line on every document and result |
| [PLAN.md](PLAN.md), [BUILD.md](BUILD.md) | The original scope and decisions, and the chunk-by-chunk build plan for the first version of Vidar |
| [stages/](stages/) | One execution packet per stage (A, B, G, H, I, J): the brief a fresh session was given, with decisions and gates |
| [results/](results/) | One write-up per chunk: what was built, what was measured, what went wrong |
| `H-status.md`, `I-status.md`, `J-status.md` | Where each stage stood, chunk by chunk and gate by gate |
| `D-testing.md`, `G-testing.md`, `H-testing.md`, `I-testing.md`, `PENDING-CHECKS.md` | Worksheets for the checks that need a person at the machine |
| [H-review.md](H-review.md) | The independent review of the Mimir stage: findings, severity and what was done about each |
| [H-review-tests/](H-review-tests/) | Test files the reviewer wrote. They are review evidence, not compiled and not part of the build |
