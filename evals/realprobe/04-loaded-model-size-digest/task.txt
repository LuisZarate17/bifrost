In crates/bifrost-core/src/ollama.rs, the struct `LoadedModel` (one entry of Ollama's `/api/ps` reply) reads only `name`, `model`, `size_vram` and `expires_at`. The reply also carries the model's whole `size` in bytes (a number) and its `digest` (a string). Add two public fields to `LoadedModel`: `size: Option<u64>` and `digest: Option<String>`, named exactly that, each read from the JSON key of the same name. A reply that has neither key (older Ollama versions, or a hand-written reply in a test) must still parse, with both fields `None`. `size_vram` keeps meaning the part that is on the GPU and must not change. Add a test in the existing `mod tests` that parses a `/api/ps` reply with the two fields and one without them. Existing code that builds a `LoadedModel` by hand will need the new fields too. Change nothing else.
